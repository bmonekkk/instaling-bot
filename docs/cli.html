instaling-bot CLI

Pełnoprawna wersja dla Linuksa, macOS i Windows w terminalu. Ten sam silnik co desktop i mobile, instalowany jedną komendą curl albo przez npx.

Linux macOS Windows Node.js 22+

Instalacja

Jedna komenda instaluje bot i jego zależności:

curl -fsSL https://raw.githubusercontent.com/bmonekkk/instaling-bot/master/install.sh | bash

Nie chcesz nic instalować globalnie? Uruchom przez npx ze źródeł w repozytorium. Bot korzysta z Chrome; jeśli go brakuje, doinstaluj przeglądarkę komendą npx puppeteer browsers install chrome.

Najważniejsze komendy

instaling-bot start          # sprawdza aktualizacje, potem uruchamia sesję
instaling-bot stats          # statystyki sesji, odpowiedzi i skuteczności
instaling-bot remind         # przypomnienie o codziennej sesji
instaling-bot update-check   # sprawdzenie najnowszego wydania
instaling-bot help           # pełna lista opcji
instaling-bot version        # wersja

instaling-bot start najpierw sprawdza najnowsze wydanie. Jeśli jest nowsza wersja, bot nie wystartuje i pokaże link do pobrania; świadomie pomiń to flagą --skip-update-check lub zmienną INSTALING_SKIP_UPDATE_CHECK=1.

Logowanie bez zapisywania hasła

Zamiast trzymać hasło w Config.json ustaw zmienne środowiskowe — mają pierwszeństwo przed konfiguracją:

export INSTALING_LOGIN="twoj_login"
export INSTALING_PASSWORD="twoje_haslo"
instaling-bot start

Przydatne w CI i na serwerach. Plik Config.json i tak zapisuje się z uprawnieniami tylko dla właściciela, a hasło jest maskowane w logach.

Częste pytania

Czy CLI działa na Windows? Tak — Windows 10+ z Node.js 22+. Najwygodniejsza jest jednak wersja z instalatorem .exe.

Czy potrzebuję GUI? Nie. CLI obsługuje sesję, statystyki i przypomnienia w całości z terminala.

Czy moje dane gdzieś trafiają? Nie. Wszystko działa lokalnie; nie ma backendu ani telemetrii.
