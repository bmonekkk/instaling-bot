Instalatory są niepodpisane. Windows SmartScreen: More info → Run anyway. macOS: kliknij instalator prawym przyciskiem → Open albo zatwierdź aplikację w System Settings → Privacy & Security. To normalne dla buildów bez certyfikatu code signing. Wszystkie wydania.

Pierwsze uruchomienie (desktop)

  1. Uruchom pobrany instalator i otwórz instaling-bot.
  2. Wpisz login i hasło do InstaLing.
  3. Ustaw poprawność odpowiedzi (domyślnie 80%) i limit odpowiedzi (0 = bez limitu).
  4. Naciśnij Start. Bot otworzy osobne okno Chrome, zaloguje się i rozpocznie lub kontynuuje sesję.
  5. Postęp, liczniki i błędy śledź w konsoli aplikacji. Przycisk Folder danych otwiera pliki konfiguracji i logi.

W ustawieniach możesz też włączyć przypomnienie o codziennej sesji (domyślnie 17:00) i jego powtarzanie co 15–180 minut, pracę w zasobniku systemowym i uruchamianie przy logowaniu. Interfejs przełączysz między polskim i angielskim przyciskami PL/EN na pasku menu — wybór zapisuje się w konfiguracji i obejmuje też menu zasobnika. Przypomnienie nie pojawi się, jeśli danego dnia bot już odpowiedział na słówka. Przycisk Statystyki pokazuje sesje, odpowiedzi, skuteczność i czas z tygodnia, miesiąca, roku lub całego okresu. Aplikacja sama sprawdza nowe wydania i pokazuje banner Pobierz.

Dane aplikacji: %APPDATA%\instaling-bot (Windows) lub ~/Library/Application Support/instaling-bot (macOS). W środku są config/Config.json, config/SavedWords.json, reminder-state.json, stats.json, logs/last-run.log, pages/ i screenshots/.

Co robi ten bot?

  • Loguje się na instaling.pl danymi z konfiguracji.
  • Automatycznie zamyka okno zgody Google (cookies), które blokowało formularz logowania.
  • Rozpoczyna lub kontynuuje sesję nauki i odpowiada na słówka.
  • Zapamiętuje poprawne tłumaczenia w SavedWords.json.
  • Domyślnie odpowiada poprawnie w 80% przypadków (valid_chance: 0.8).
  • Błędne odpowiedzi losuje równo między puste pole, inne zapisane tłumaczenie i literówkę.
  • Obsługuje języki dostępne na instaling.pl (m.in. angielski, niemiecki, francuski, włoski i hiszpański).

CLI: Linux i terminal

Wersja CLI jest wspierana tak długo, jak istnieje aplikacja desktopowa. To zalecany wariant dla Linuksa i wszystkich osób, które wolą terminal. Wymaga Node.js 22+.

Najszybciej zainstalujesz CLI jedną komendą (wymaga Node.js 22+):

curl -fsSL https://raw.githubusercontent.com/bmonekkk/instaling-bot/master/install.sh | bash

Instalator zapisze program w ~/.local/share/instaling-bot i doda launcher instaling-bot w ~/.local/bin. Alternatywnie możesz sklonować repozytorium:

git clone https://github.com/bmonekkk/instaling-bot.git
cd instaling-bot
npm install --omit=dev
cp config/Config.defaults.json config/Config.json

Wpisz login i hasło w config/Config.json, a następnie uruchom:

instaling-bot start
instaling-bot stats                  # tydzień, miesiąc, rok i całość
instaling-bot stats --period month
instaling-bot remind                 # przypomnienie w tle
instaling-bot update-check
instaling-bot help

Przed startem CLI sprawdza najnowsze wydanie i nie uruchamia nieaktualnej wersji. Pomijanie: --skip-update-check lub INSTALING_SKIP_UPDATE_CHECK=1. Aktualizacja: curl ponownie lub git pull && npm install --omit=dev.

Jeśli Puppeteer nie pobrał przeglądarki podczas instalacji, uruchom npx puppeteer browsers install chrome.

Najważniejsze opcje

  • valid_chance - jaka część odpowiedzi ma być poprawna (0.8 = 80%); reszta to losowy błąd: puste pole, inne tłumaczenie lub literówka.
  • max_answers - limit odpowiedzi w jednym uruchomieniu (0 = bez limitu).
  • delays.click_min / click_max - pauza po kliknięciu (domyślnie 2000-4500 ms).
  • delays.type_min / type_max - opóźnienie na pojedynczą literę.
  • delays.typo_chance - szansa na symulowaną literówkę z backspace (0.15 = 15%).
  • delays.type_pause_chance - szansa na dodatkową pauzę w trakcie pisania.
  • delays.quick_click_min / quick_click_max - szybkie pauzy po kliknięciach nawigacyjnych.
  • reminder.enabled / reminder.time - codzienne przypomnienie o sesji (HH:MM, domyślnie 17:00).
  • reminder.repeat_minutes - powtarzanie przypomnienia co N minut (0 = raz dziennie).
  • language - język interfejsu desktopowego (pl / en), przełączany przyciskami PL/EN na pasku menu.
  • background.run_in_tray / start_at_login - praca w zasobniku i autostart (desktop).
  • show_browser - pokazuje okno Chrome; ustaw false na serwerze bez GUI.
  • debug - dodatkowe logi z przeglądarki i zrzuty stron.

Desktop pokazuje najważniejsze opcje w GUI, a pełny plik można edytować ręcznie. Wzór: config/Config.defaults.json.

Najczęstsze problemy

  • Brak internetu / offline - sprawdź połączenie z internetem i spróbuj ponownie. Okno zamyka się tylko przyciskiem Zamknij, a pomoc znajdziesz w FAQ w README.
  • SmartScreen / Gatekeeper ostrzega - instalatory są niepodpisane. Windows: More info → Run anyway. macOS: prawy przycisk → Open lub ustawienia prywatności.
  • Bot nie przechodzi logowania - sprawdź login i hasło. Bot wpisuje je dokładnie i sam ponawia próbę raz, jeśli strona chwilowo odrzuci formularz.
  • Brak Chrome w CLI - uruchom npx puppeteer browsers install chrome. Desktop ma Chrome w instalatorze.
  • Strona zmieniła układ - włącz "debug": true i sprawdź pliki w pages/ oraz screenshots/.
  • Chcesz szybciej / wolniej - zmień wartości w sekcji delays w Config.json lub w panelu humanizacji.
  • Duże zużycie RAM w tle - włącz tryb zasobnika; zamknięcie okna niszczy renderer i zostaje lekki proces główny (ok. 50 MB, poniżej 100 MB także po zamknięciu wcześniej otwartego okna).
  • macOS: brak ikony w Docku - to zamierzone w trybie zasobnika. Kliknij ikonę w menu bar, żeby wrócić do okna i Docka.
  • Autostart otwiera okno - włącz także tryb zasobnika. Sam autostart nie uruchamia aplikacji po cichu.

English summary

instaling-bot is an open-source (ISC) bot for instaling.pl vocabulary practice. It ships as a desktop app for Windows 10/11 and macOS 13+ with a bundled Chrome for Testing, and as a Node.js 22+ CLI for Linux, macOS and Windows. The app logs in, starts or resumes a session, answers prompts, remembers translations and can deliberately make believable mistakes for human-like behaviour.

Version 3.2.0 adds week, month, year and all-time statistics, repeating reminders, a new CLI (start, stats, remind, update-check) and update checks before the CLI starts. Installers are unsigned, so SmartScreen or Gatekeeper may warn on first launch.

Read the English README, browse the wiki or ask in Discussions.
