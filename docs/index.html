instaling-bot

Działający, otwartoźródłowy bot do automatycznego rozwiązywania słówek na instaling.pl. Wersja 2.2.1 pisze jeszcze bardziej po ludzku: losowe opóźnienia między literami, symulowane literówki i szybkie, pewne logowanie.

Node.js 22+ Puppeteer 25 v2.2.1 Human-like typing Licencja ISC Open source

Pobierz v2.2.1 Zobacz kod na GitHub

Nowość: bardziej ludzkie pisanie

  • Każda litera ma własne, losowe opóźnienie.
  • Losowe mikro-pauzy w trakcie pisania.
  • Czasem zły klawisz, backspace i poprawna litera.
  • Gdy valid_chance każe odpowiedzieć źle, bot wpisuje wiarygodną literówkę zamiast pustego pola.
  • Logowanie: szybkie, dokładne wpisanie danych i jedna automatyczna ponowna próba.
  • Przyciski nawigacji (kontynuuj, rozpocznij) reagują od razu.

Co robi ten bot?

  • Loguje się na instaling.pl danymi z config/Config.json.
  • Automatycznie zamyka okno zgody Google (cookies), które blokowało formularz logowania.
  • Rozpoczyna lub kontynuuje sesję nauki i odpowiada na słówka.
  • Zapamiętuje poprawne tłumaczenia w config/SavedWords.json.
  • Domyślnie odpowiada poprawnie w 80% przypadków (valid_chance: 0.8).
  • Obsługuje języki dostępne na instaling.pl (m.in. angielski, hiszpański, niemiecki).

Instalacja

  1. Zainstaluj Node.js 22 lub nowszy: nodejs.org.
  2. Sklonuj repozytorium i zainstaluj zależności:
git clone https://github.com/Bmoneczek/instaling-bot.git
cd instaling-bot
npm install

Skopiuj config/Config.defaults.json do config/Config.json i uzupełnij dane logowania:

{
    "credentials": {
        "login": "twoj-login-lub-email",
        "password": "twoje-haslo"
    }
}

Uruchom bota:

npm start

Najważniejsze opcje

  • valid_chance - jaka część odpowiedzi ma być poprawna (0.8 = 80%).
  • max_answers - limit odpowiedzi w jednym uruchomieniu (0 = bez limitu).
  • delays.type_min / type_max - opóźnienie na pojedynczą literę.
  • delays.typo_chance - szansa na symulowaną literówkę z backspace (0.15 = 15%).
  • delays.type_pause_chance - szansa na dodatkową pauzę w trakcie pisania.
  • delays.quick_click_min / quick_click_max - szybkie pauzy po kliknięciach nawigacyjnych.
  • show_browser - pokazuje okno Chrome; ustaw false na serwerze bez GUI.
  • debug - dodatkowe logi z przeglądarki i zrzuty stron.

Pełny wzór: config/Config.defaults.json.

Najczęstsze problemy

  • Bot nie przechodzi logowania - sprawdź login i hasło. Bot wpisuje je dokładnie i sam ponawia próbę raz, jeśli strona chwilowo odrzuci formularz.
  • Brak Chrome - uruchom npx puppeteer browsers install chrome.
  • Strona zmieniła układ - włącz "debug": true i sprawdź pliki w pages/ oraz screenshots/.
  • Chcesz szybciej / wolniej - zmień wartości w sekcji delays w config/Config.json.
