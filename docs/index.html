instaling-bot

Działający, otwartoźródłowy bot do automatycznego rozwiązywania słówek na instaling.pl. Naprawiony w 2026: obsługa okna cookies, nowy Puppeteer i aktualne selektory strony.

Node.js 22+ Puppeteer 25 Chrome 156 Licencja ISC Open source
Pobierz najnowszą wersję Zobacz kod na GitHub

Co robi ten bot?

  • Loguje się na instaling.pl danymi z config/Config.json.
  • Automatycznie zamyka okno zgody Google (cookies), które blokowało formularz logowania.
  • Rozpoczyna sesję nauki i odpowiada na słówka.
  • Zapamiętuje poprawne tłumaczenia w config/SavedWords.json.
  • Obsługuje języki dostępne na instaling.pl (m.in. angielski, hiszpański, niemiecki).

Instalacja

git clone https://github.com/Bmoneczek/instaling-bot.git
cd instaling-bot
npm install

Następnie uzupełnij config/Config.json (wzór: config/Config.example.json):

{
    "credentials": {
        "login": "twoj-login-lub-email",
        "password": "twoje-haslo"
    }
}

I uruchom:

npm start

Najczęstsze problemy

  • Bot nie przechodzi logowania - wersja 2.0.0 naprawia nakładkę cookies Google. Upewnij się, że używasz najnowszego release'a.
  • Brak Chrome - uruchom npx puppeteer browsers install chrome.
  • Strona zmieniła układ - włącz "debug": true i sprawdź pliki w pages/ oraz screenshots/.
