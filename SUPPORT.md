# Support

## Where to ask

| I need… | Go to |
|---|---|
| Help using the app or CLI | [Discussions → Q&A](https://github.com/bmonekkk/instaling-bot/discussions/categories/q-a) |
| To report a reproducible bug | [Issues → Bug report](https://github.com/bmonekkk/instaling-bot/issues/new?template=bug_report.yml) |
| To suggest a feature | [Discussions → Ideas](https://github.com/bmonekkk/instaling-bot/discussions/categories/ideas) or the feature template |
| To report a security problem | [SECURITY.md](SECURITY.md) — never a public issue |
| Documentation and FAQ | [Wiki](https://github.com/bmonekkk/instaling-bot/wiki) and [README](README.md) |
| A new version | [Latest release](https://github.com/bmonekkk/instaling-bot/releases/latest) |

## Before asking

1. Read the [README FAQ](README.md#-rozwiązywanie-problemów) and the wiki troubleshooting page.
2. Update to the latest release.
3. Search existing issues and discussions.
4. Prepare: version, operating system, install method, exact error and redacted logs.

**Never post passwords, cookies, tokens, `Config.json`, `SavedWords.json` or screenshots
with personal data.** Redact first.

## What to expect

This is a hobby project maintained by one person. Support is best-effort:

- security reports are prioritised,
- reproducible bugs are usually triaged within a week,
- feature requests are welcome but not guaranteed,
- issues without enough information may be closed with a request for details.

There is no paid support, SLA or guaranteed response time. Please be patient and kind.
