# Code of Conduct

## Our pledge

We want this project to be a friendly place for everyone, regardless of experience,
language, nationality, gender, age, disability, appearance or technical background.
Możesz pisać po polsku lub po angielsku.

## Our standards

Examples of positive behaviour:

- being respectful and patient,
- giving constructive feedback about code, not people,
- welcoming beginners and explaining things without condescension,
- respecting different opinions and use cases,
- crediting other people's work,
- protecting privacy: never posting credentials, logs or personal data.

Examples of unacceptable behaviour:

- harassment, insults, threats or discriminatory comments,
- sexualised language or attention,
- trolling, deliberate derailing or personal attacks,
- publishing someone's private information without permission,
- encouraging cheating, account abuse or breaking the law,
- repeated spam or self-promotion unrelated to the project.

## Scope

This code applies in the repository, issues, pull requests, discussions, wiki, release
comments and any other project space, as well as when representing the project elsewhere.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainer
[@bmonekkk](https://github.com/bmonekkk) through GitHub. For sensitive reports, use
[private vulnerability reporting](https://github.com/bmonekkk/instaling-bot/security/advisories/new)
or ask for a private channel first.

Please include what happened, where, when and any relevant links or screenshots. Reports
will be handled as confidentially as possible.

## Enforcement

Maintainers may:

1. ask for a correction or apology,
2. remove or edit comments, issues or discussions,
3. issue a warning,
4. temporarily restrict participation,
5. permanently ban a participant.

The response will be proportional to the behaviour and the harm caused. Retaliation
against someone who reports a problem is not acceptable.
